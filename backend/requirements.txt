# --- Web framework ---
# These versions are pinned deliberately, not arbitrarily: a newer FastAPI
# pulled in without pinning (e.g. from a bare `pip install fastapi`, or a
# stale/conflicting global install shadowing your venv) has been observed
# to change how routers are registered internally, which can cause routes
# like /api/auth/login to intermittently 404 even though the code is
# correct. If you ever hit that, run `pip show fastapi` inside your
# activated venv and confirm it says exactly 0.115.0 — see
# docs/SETUP.md's troubleshooting section.
