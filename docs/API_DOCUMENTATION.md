# API Documentation

Base URL (local): `http://localhost:8000`
Interactive docs (auto-generated by FastAPI from the code): `http://localhost:8000/docs`

All endpoints except `/api/health`, `/api/auth/register`, and
`/api/auth/login` require an `Authorization: Bearer <token>` header.

## Auth

### `POST /api/auth/register`
```json
// request
{ "name": "Jane Doe", "email": "jane@example.com", "password": "at-least-8-chars" }
// response 201
{ "access_token": "eyJ...", "token_type": "bearer" }
```
`400` if the email is already registered. `422` if the password is under 8 characters.

### `POST /api/auth/login`
```json
// request
{ "email": "jane@example.com", "password": "at-least-8-chars" }
// response 200
{ "access_token": "eyJ...", "token_type": "bearer" }
```
`401` on wrong email/password (deliberately the same error for both, so a
failed login never reveals whether an email is registered).

### `GET /api/auth/me`
```json
// response 200
{ "id": "uuid", "name": "Jane Doe", "email": "jane@example.com" }
```

## Documents

### `POST /api/documents`
`multipart/form-data`, field name `file`. Accepts `.pdf .docx .txt .md .csv`, max 25MB.

Processing runs synchronously — the response only arrives once
extraction, chunking, embedding, and indexing have finished (or failed).

```json
// response 201
{
  "id": "uuid", "file_name": "notes.pdf", "file_type": "pdf",
  "file_size": 48213, "page_count": 12,
  "processing_status": "completed",   // or "failed"
  "processing_error": null,           // populated if failed, e.g. "No text could be extracted..."
  "created_at": "2026-01-01T12:00:00"
}
```
`422` if the file type is unsupported, the file is empty, or it exceeds the size limit.

### `GET /api/documents`
Returns the current user's documents, newest first. Never includes another user's documents.

### `GET /api/documents/{id}` / `DELETE /api/documents/{id}`
`404` (not `403`) if the document doesn't exist **or** belongs to another user.

### `POST /api/documents/{id}/reprocess`
Re-runs the ingestion pipeline (useful after a transient failure, e.g. the
embedding model couldn't be downloaded the first time).

## Chat

### `POST /api/chat/conversations`
```json
// request
{ "document_ids": ["uuid1", "uuid2"], "title": "optional" }
// response 201
{ "id": "uuid", "title": "New conversation", "document_ids": ["uuid1","uuid2"],
  "created_at": "...", "updated_at": "..." }
```
`400` if any `document_ids` entry doesn't belong to the current user.

### `GET /api/chat/conversations`
List the current user's conversations, most recently updated first.

### `DELETE /api/chat/conversations/{id}`
Deletes the conversation and its messages/citations.

### `GET /api/chat/conversations/{id}/messages`
```json
[
  { "id": "uuid", "role": "user", "content": "What is supervised learning?",
    "created_at": "...", "citations": [] },
  { "id": "uuid", "role": "assistant", "content": "Supervised learning uses labeled data [1].",
    "created_at": "...",
    "citations": [
      { "index": 1, "document_id": "uuid", "source_name": "ml_notes.pdf",
        "page": 4, "excerpt": "Supervised learning is a type of...", "relevance_score": 0.83 }
    ] }
]
```

### `POST /api/chat/conversations/{id}/ask`
```json
// request
{ "question": "What is supervised learning?" }
// response 200 — a single assistant MessageResponse, shape as above
```
If no `GROQ_API_KEY` is configured (or the Groq call fails), the
`content` field contains the extractive fallback text (raw excerpts) —
citations are still populated normally either way.

### `POST /api/chat/messages/{message_id}/feedback`
```json
// request
{ "rating": "helpful", "comment": "optional" }   // rating: "helpful" | "not_helpful"
// response 204
```

## Analytics

### `GET /api/analytics/summary`
```json
{
  "total_documents": 3, "completed_documents": 2, "failed_documents": 1,
  "total_conversations": 5, "total_messages": 22
}
```
Every field is a live `COUNT(*)` query scoped to the current user — never a fabricated or cached estimate.

## Health

### `GET /api/health`
```json
{ "status": "ok", "app": "Talkify 2.0" }
```
No auth required. Useful for Docker healthchecks / uptime monitors.

## Error format

FastAPI's default error shape is used throughout:
```json
{ "detail": "Human-readable message" }
```
or, for Pydantic validation errors (`422`), a `detail` array with
per-field messages (FastAPI's standard format, visible directly in
`/docs`).
